# DualHolo Analyze v0.5.0

再生像の表示・保存に使うパディングを「なし／4k／8k」から選べるようにしました。
深度の上下ボタンには0.02 mm・0.05 mmの刻みを追加しました。
従来のDualHoloとは別アプリとして配布します。

- 「深度・保存」とキャリブレーションの焦点合わせに、表示パディングの選択を追加。同じ深度・拡大率・スクロール位置を保って再生します。
- 4k／8kでは入力場を中央に配置し、周囲を場の平均値で埋めます。表示・保存は元の画像領域のみです。「なし」は元画像サイズで計算します。
- Tamura焦点探索は平均値パディング（既定4096×4096）に変更。表示条件だけを変えても探索済み曲線とGS位相場は保持し、GSを繰り返しません。
- TIFFは選択中の条件のfloat32強度、PNGは表示画像を保存。既定ファイル名と条件JSONに表示パディングを記録し、探索の計算条件も区別します。
- 上下の刻みは0.02／0.05／0.1／0.2／1／2 mm。上下ボタンを押すと直ちに再生を開始します。
- 表示用に計算した深度はパディング別に再利用。切り出した画像だけを保持し、メモリ上限を超えた分は一時ファイルへ退避します。Tamura探索画像のスタックは保持しません。
- 8kもCPUで計算し、進捗表示・中断に対応。連続操作では最後の深度・パディングを優先します。GS往復は常に帯域制限なしです。

展開して`DualHoloAnalyze`を起動してください。Pythonの別途インストールは不要です。
カメラやSDKなしで起動でき、「シミュレーション」と保存画像の解析を使用できます。
実カメラには別途Spinnaker SDKとドライバが必要です。
カメラ設定は変更せず、DualHoloと同じ排他ロックで重複接続を防ぎます。

各OSで4k・8kの数値検証、較正からGSまでのGUIテスト、配布版の未接続起動・模擬入力を検証します。実カメラはこの検証の対象外です。
macOSのDeveloper ID署名・公証とWindowsのAuthenticode署名はありません。
操作と設定は同梱README、SHA-256は各アーカイブと同名の`.sha256`を参照してください。
