# DualHolo Analyze v0.3.0

cam0・cam1の探索範囲を個別に指定できるようにし、Tamura探索は元画像サイズ・パディングなしへ変更しました。
深度画像スタックを保持せず、選択した深度をその都度4k平均値パディングで再生します。
従来のDualHoloとは別アプリとして配布します。

- cam0・cam1のmin/maxをGUI・YAMLで個別設定。位相回復後の探索はcam0の範囲を使用。
- 深度の上下ボタンは0.1 mm／1 mmを選択でき、押すと直ちに再生。Enter、スライダー、曲線クリックも対応。
- 表示中の深度だけ帯域制限あり／なしを保持し、切り替えを即時反映。GS往復は従来どおり常に帯域制限なし。
- 位置合わせを以前の採用方式に合わせ、暗いドットの強調、複数領域の大域対応、128 px窓・±12 px探索、頑健な二次変換へ修正。既定測定間隔256 px。
- ベクトル図に画像座標、変位量カラーバー、矢印キー、RMSを追加。表示密度を抑制。
- 読込時の時刻差を「ホスト時計へ換算した推定露光時刻差」と明示し、記録された不確かさも表示。ペア選択に両時計の不確かさを加算。
- 元画像サイズでの探索に合わせ、山型ピークの既定最小突出率を0.5%に調整。端点の最大値は引き続き除外。

展開して`DualHoloAnalyze`を起動してください。Pythonの別途インストールは不要です。
カメラやSDKなしで起動でき、「シミュレーション」と保存画像の解析を使用できます。
実カメラには別途Spinnaker SDKとドライバが必要です。
カメラ設定は変更せず、DualHoloと同じ排他ロックで重複接続を防ぎます。

Tamura探索は元画像サイズ・パディングなし、表示・GSは既定4096×4096の平均値パディングです。
各OSで数値検証、較正からGSまでのGUIテスト、配布版の未接続起動・模擬入力を検証します。実カメラはこの検証の対象外です。
macOSのDeveloper ID署名・公証とWindowsのAuthenticode署名はありません。
操作と設定は同梱README、SHA-256は各アーカイブと同名の`.sha256`を参照してください。
