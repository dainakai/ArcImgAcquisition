# DualHolo Analyze v0.2.0

キャリブレーションと撮影・解析をタブに分け、ガラスプレートの撮影から面間距離・画像変換の適用、2面GS位相回復までアプリ内で行えるようにしました。
従来のDualHoloとは別アプリとして配布します。

- 各カメラのTamura曲線から山型ピークを検出し、数値・スライダー・曲線クリックで焦点を微調整。面間距離は`z0 − z1`から算出。
- 補正前後のベクトルと変換後cam1画像を確認してから、撮影タブへ明示的に適用。距離・マップ・条件を保存して再利用。
- 探索した全深度の再生画像を保持。メモリを超えた分も一時キャッシュへ保存し、計算済み深度ではFFTを再実行しません。
- CPU計算は既定4スレッド、設定で1〜4を選択。波長、画素ピッチ、平均値パディングのサイズもGUIとYAMLで設定。
- GSの往復伝搬は常に帯域制限なし。後段の再生表示は帯域制限あり／なしを事前計算して切替。
- Recボタンを削除し、Capture・Resume・明示保存に整理。入力パス、日本語ツールチップ、画像領域と操作欄の配置を改善。

展開して`DualHoloAnalyze`を起動してください。Pythonの別途インストールは不要です。
カメラやSDKなしで起動でき、「シミュレーション」と保存画像の解析を使用できます。
実カメラには別途Spinnaker SDKとドライバが必要です。
カメラ設定は変更せず、DualHoloと同じ排他ロックで重複接続を防ぎます。

既定の光伝搬は4096×4096の平均値パディング、表示・評価は元画像領域です。
各OSで数値検証、較正からGSまでのGUIテスト、配布版の未接続起動・模擬入力を検証します。実カメラはこの検証の対象外です。
macOSのDeveloper ID署名・公証とWindowsのAuthenticode署名はありません。
操作と設定は同梱README、SHA-256は各アーカイブと同名の`.sha256`を参照してください。
