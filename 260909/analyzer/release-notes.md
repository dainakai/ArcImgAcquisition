# DualHolo Analyze v0.4.0

cam0 Gaborと位相回復の再生像を、拡大・スクロール位置を保ったまま切り替えられるようにしました。
深度の数値欄と刻みの選択を別行に分け、誤操作を減らしました。
従来のDualHoloとは別アプリとして配布します。

- 再生像の上部にcam0 Gabor／位相回復の表示切替を追加。同じ深度・倍率・スクロール位置・明暗範囲で比較。
- キャリブレーション適用後のcam0 Gabor／位相回復のAnalyzeでGSを一度実行。各深度の両再生像を準備し、トグル操作では再計算しない。
- 未較正・不適合の画像ペアでは比較を無効化。条件や入力を変えた場合も以前の比較結果を破棄。
- Tamura曲線はAnalyzeで指定したモードを維持し、計算モードを明示。保存画像と曲線それぞれのモードをJSONへ記録。
- 深度の上下ボタンと刻みの選択を別行に配置。刻みは0.1 mm／0.2 mm／1 mm／2 mm。上下ボタンで直ちに再生。
- 深度画像スタックは保持せず、表示中の深度だけ両モード・帯域制限あり／なしを保持。GS往復は従来どおり常に帯域制限なし。

展開して`DualHoloAnalyze`を起動してください。Pythonの別途インストールは不要です。
カメラやSDKなしで起動でき、「シミュレーション」と保存画像の解析を使用できます。
実カメラには別途Spinnaker SDKとドライバが必要です。
カメラ設定は変更せず、DualHoloと同じ排他ロックで重複接続を防ぎます。

Tamura探索は元画像サイズ・パディングなし、表示・GSは既定4096×4096の平均値パディングです。
各OSで数値検証、較正からGSまでのGUIテスト、配布版の未接続起動・模擬入力を検証します。実カメラはこの検証の対象外です。
macOSのDeveloper ID署名・公証とWindowsのAuthenticode署名はありません。
操作と設定は同梱README、SHA-256は各アーカイブと同名の`.sha256`を参照してください。
